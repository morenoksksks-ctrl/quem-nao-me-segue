# Quem Não Me Segue

Extensão gratuita para Chrome que mostra quem você segue no Instagram e não te segue de volta, e avisa quando alguém deixa de te seguir. Somente leitura: não segue, não deixa de seguir e não pede senha.

- **Política de Privacidade:** [PRIVACIDADE.md](PRIVACIDADE.md)
- **Suporte e dúvidas:** abra uma [issue](https://github.com/morenoksksks-ctrl/quem-nao-me-segue/issues) (não inclua senhas nem dados pessoais).

Projeto independente, sem vínculo com o Instagram ou a Meta Platforms, Inc.
